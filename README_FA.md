# مرتب خونه — نسخه Flutter ۰.۴

این بسته یک اسکلت اولیه Flutter برای اتصال به Supabase است؛ **APK آماده نیست** و هنوز در محیط واقعی کامپایل و آزمایش نشده است.

## امکانات فعلی
- راه‌اندازی Supabase با URL و publishable key پروژه
- ورود ایمیل/رمز عبور
- خواندن پروفایل از `public.profiles`
- بررسی `is_active` و نمایش نقش
- داشبورد اولیه فارسی و راست‌چین
- خروج از حساب

## پیش‌نیاز دیتابیس
جدول `public.profiles` باید ستون‌های زیر را داشته باشد:
- `id` (UUID برابر با `auth.users.id`)
- `full_name`
- `role`
- `is_active` (boolean)

## نکته مهم امنیتی
کلید publishable داخل برنامه موبایل قابل مشاهده است و این طبیعی است. امنیت باید با RLS و سیاست‌های صحیح دیتابیس تأمین شود. هرگز `service_role` یا `sb_secret` را در اپ قرار ندهید. پیش از استفاده واقعی، سیاست‌های RLS و امکان تغییر نقش کاربران از سمت خود کاربر باید بازبینی و آزمایش شوند. این بسته ممیزی امنیتی انجام نمی‌دهد.

## اجرای محلی
```bash
flutter pub get
flutter run
```

## ساخت APK
```bash
flutter build apk --release
```

برای ساخت ابری می‌توان پروژه را در GitHub قرار داد و workflow پوشه `.github/workflows` را اجرا کرد. ساخت APK نیازمند تکمیل build در CI است؛ این ZIP خودش APK نیست.

## ورود
از صفحه ورود با همان ایمیل و رمز عبور کاربری که در Supabase Authentication ساخته‌اید استفاده کنید.
